Audio Themes NG и Фонетическая пунктуация (Phonetic Punctuation)

Это дополнение обеспечивает захватывающий звуковой опыт для пользователей программы чтения экрана NVDA, воспроизводя звуки для различных событий пользовательского интерфейса. Оно позволяет создавать, устанавливать и настраивать аудио темы, улучшая звуковую обратную связь от интерфейса.

Возможности

  • Звуковые эффекты: Воспроизводит звуки для событий пользовательского интерфейса, таких как фокусировка на элементах управления, навигация по спискам и многое другое.
  • 3D звук: Использует Steam Audio для обеспечения трехмерного позиционного звука, давая представление о том, где находятся элементы управления на экране.
  • Расширенный аудио DSP: Обработка звука в реальном времени, включая усиление басов (Bass Boost), шумоподавитель (Noise Gate), обрезку тишины (Silence Trimming), умную нормализацию громкости и плавные огибающие (Smooth Envelopes).
  • Приглушение звука (Audio Ducking): Автоматически снижает громкость темы, когда NVDA говорит, чтобы обеспечить четкость речи.
  • Реверберация (Reverb): Добавляет эффекты реверберации к звуку для более захватывающего опыта.
  • Настраиваемые темы: Позволяет пользователям создавать, устанавливать и переключаться между различными аудио темами.
  • Студия Аудио Тем (Audio Themes Studio V2): Встроенный инструмент для создания новых аудио тем или редактирования существующих прямо с микрофона или путем перетаскивания файлов (drag & drop).
  • Расширенные аудио форматы: Встроенная поддержка FFmpeg для MP3, FLAC, OGG, M4A и других.
  • Расширенные звуки набора текста: Имитирует набор текста на физической клавиатуре с пространственным позиционированием звука, динамической регулировкой громкости (в зависимости от скорости) и умным назначением клавиш для специальных клавиш (Enter, Backspace, Пробел, Shift, Ctrl, Alt).
  • Контекстный набор текста: Возможность ограничить воспроизведение звуков набора текста только в редактируемых текстовых полях.
  • Умные индикаторы выполнения: Динамическое изменение высоты тона для индикаторов выполнения (выше тон = больший процент).
  • Обнаружение первого/последнего элемента: Воспроизводит специфический звук столкновения (bump) при достижении границы списка или меню.
  • Аудио маяк / Сонар (Audio Beacon / Sonar): Оставьте пространственный аудио маяк в любом месте экрана и перемещайтесь вокруг, чтобы слышать эхо сонара в реальном времени, ориентируясь относительно маяка.
  • Расширенная навигация: Встроенные движки SentenceNav и BrowserNav для плавной навигации по тексту и веб-страницам без конфликтов со стрелками клавиатуры.
  • Слой навигации (Navigation Layer): Нажмите NVDA+Win+N, чтобы войти в режим быстрой навигации, где стрелки перемещают по предложениям, абзацам или другим элементам без удержания клавиш-модификаторов.
  • Облачный магазин тем (Cloud Theme Store): Скачивайте, прослушивайте и устанавливайте темы, созданные сообществом, прямо из Студии Аудио Тем.

  • Профили приложений: Автоматически переключайтесь на определенную аудио тему и пакет звуков набора текста в зависимости от активного приложения.

  • Звуки состояния системы (System Status Sounds): Воспроизводит звуковые сигналы для событий системного уровня, таких как изменения питания от сети переменного тока, состояние батареи, подключение USB-устройств и подключение к сети.

Как использовать

Включение/выключение аудио тем

Вы можете включить или выключить функцию аудио тем в настройках NVDA:

  1. Откройте меню NVDA (NVDA+N).
  2. Перейдите в "Параметры" -> "Настройки".
  3. В диалоговом окне настроек выберите категорию "Аудио темы".
  4. Установите или снимите флажок "Включить аудио темы".

Выбор и управление темами

  • О теме: Нажмите кнопку "О теме" (About), чтобы просмотреть информацию о выбранной теме.

Обзор вкладок настроек

Панель расширенных настроек аудио тем содержит несколько вкладок для настройки каждого аспекта звукового восприятия. Ниже подробно описана каждая доступная опция:

1. Вкладка "Общие" (General)

  • Включить аудио темы: Главный переключатель для включения или выключения движка аудио тем.
  • Выбрать тему: Выпадающее меню для выбора активной аудио темы из установленных.
  • О теме / Удалить / Добавить новую: Управление вашими темами. Вы можете устанавливать новые темы из файлов .atp или .zip.
  • Магазин тем: Открывает встроенный магазин для загрузки тем, созданных сообществом.
  • Студия тем: Открывает студию для редактирования или ремикширования текущей выбранной темы.
  • Предпросмотр: Воспроизводит последовательность примеров звуков из активной темы.
  • Воспроизводить звуки в режиме 3D: Включает пространственную обработку звука.
  • Озвучивать роли: Переключает, будет ли NVDA произносить роли элементов управления (например, "кнопка", "ссылка").
  • Озвучивать роли при непрерывном чтении: Переключает произнесение ролей при непрерывном чтении. С помощью кнопки "Выбрать роли..." вы можете точно указать, какие роли произносить.
  • Использовать громкость синтезатора речи: Связывает громкость темы с громкостью голоса NVDA. Отключите это, чтобы использовать ручной ползунок.
  • Приглушение звука (Audio Ducking): Снижает громкость фонового звука, когда NVDA говорит. Вы можете выбрать, какие категории звуков будут приглушаться, и задать процент приглушения.
  • Резервное поведение (Fallback): Определяет, что происходит, когда отсутствует звук для определенной роли или первого/последнего элемента (например, воспроизвести тишину, воспроизвести пользовательский звук или воспроизвести первый доступный звук).
  • Звуки состояния подавляют звук роли: Если у элемента есть звук состояния (например, отмеченный флажок), это предотвратит воспроизведение звука роли, чтобы избежать звукового шума.
  • Черный список приложений: Разделенный запятыми список исполняемых файлов приложений, в которых аудио темы должны быть полностью отключены. Вы также можете настроить, какие именно категории звуков будут подавляться в этих приложениях.
  • Звуки набора текста: Включите звуки печатной машинки или механической клавиатуры. Опции включают пространственный набор текста (имитация физического расположения клавиш), умное сопоставление, ограничение звуков полями редактирования, выбор звуковых пакетов и регулировку громкости.
  • Управление конфигурацией: Проверяйте обновления, включайте бета-версии и экспортируйте/импортируйте всю вашу конфигурацию (включая темы, правила и звуки) в один файл .atcfg.

2. Вкладка "Звуковой движок" (Audio Engine)

  • Умная нормализация громкости: Динамически подстраивает тихие и громкие звуки к постоянному уровню.
  • Плавная огибающая (Smooth Envelope): Применяет микро-затухания (fade-in и fade-out), чтобы предотвратить щелчки в звуке.
  • Плавное 3D-панорамирование: Создает эффект скольжения, когда объекты перемещаются по экрану, а не мгновенно перепрыгивают.
  • Кэширование в ОЗУ: Загружает звуки в память для воспроизведения с нулевой задержкой.
  • Обрезка тишины: Автоматически удаляет тишину в начале и конце аудиофайлов на основе настраиваемого порога.
  • Шумоподавитель (Noise Gate): Устраняет слабый фоновый шум из плохо записанных аудио тем. Включает ползунки Порога, Атаки и Восстановления.
  • Усиление басов (Bass Boost): Усиливает низкие частоты, чтобы придать звукам больше плотности. Включает ползунки Усиления и Частоты среза.
  • Режим вывода звука: Переключение между полным пространственным 3D-аудио (Стерео) и центрированным (Моно).
  • Пространственное аудио индикатора выполнения: Выберите, будут ли индикаторы выполнения панорамироваться слева направо в зависимости от их процента выполнения или их физического расположения на экране. Также включает переключатель для повышения тона по мере увеличения процента выполнения.

3. Вкладка "Реверберация" (Reverb)

Имитирует акустику окружающей среды, создавая ощущение, что звуки воспроизводятся в реальном помещении. - Включить реверберацию: Главный переключатель для эффектов окружения. - Размер комнаты: Регулирует воспринимаемый размер виртуальной комнаты. - Затухание (Damping): Управляет скоростью поглощения высоких частот (имитация мягких и жестких стен). - Уровень эффекта / Исходный сигнал (Wet / Dry): Балансирует количество обработанной реверберации с оригинальным чистым звуком. - Ширина (Width): Регулирует стерео базу хвоста реверберации.

4. Вкладка "Форматы аудио" (Audio Formats)

  • Использовать FFmpeg: Включает поддержку сжатых аудиоформатов, таких как MP3, FLAC, M4A и OGG.
  • Статус FFmpeg: Показывает, установлен ли FFmpeg. Если нет, предоставляется кнопка для автоматической загрузки и извлечения (~12 МБ).

5. Вкладка "Аудио и речевые правила" (Earcons & Speech Rules)

Мощный движок правил для фонетического произношения и пользовательских звуков состояний. - Список правил: Отображает все активные правила, отфильтрованные по категориям (Роль, Состояние, Текст, Символ и т.д.). - Редактор правил: При добавлении или редактировании правила вы можете определить: - Шаблон / Значение: Шаблон регулярного выражения (Regex), роль или состояние для совпадения. - Тип действия: Выберите воспроизведение встроенного звука, пользовательского WAV-файла, звукового сигнала (beep), изменение просодии (тон/скорость), замену текста или ничего не делайте. - Действие речи: Решите, должна ли NVDA сохранять исходный текст, редактировать произносимый текст или полностью замолчать при совпадении правила. - Настройки звука: Ползунок громкости, смещения обрезки начала/конца (в миллисекундах), тон/продолжительность для сигналов. - Фильтры: Ограничьте правило конкретными приложениями, заголовками окон или URL-адресами веб-сайтов (поддерживается Regex). - Пакетные операции: Экспорт/Импорт словарей правил, включение/выключение всех правил или тестирование правил прямо из интерфейса.

6. Вкладка "Разное" (Miscellaneous)

Расширенная конфигурация для модулей навигации. - Навигация по предложениям (Alt+Стрелки): Регулировка громкости звуковых сигналов для границ абзацев, переключение объявлений форматирования, настройка пропуска ссылок Википедии, регулировка реконструкции предложений между абзацами и определение пользовательских символов разделения предложений/фраз. - Текстовая навигация (Alt+Shift+Стрелки): Регулировка громкости треска (crackle) и настройка поведения звуковых сигналов в конце текста. - Расширенная браузерная навигация (BrowserNav): Регулировка громкости треска и звуковых сигналов во время навигации QuickSearch, а также громкости звукового сигнала пропуска помех (Skip Clutter). - Слой навигации (NVDA+Win+N): Настройка таймаутов автовыхода, звуков действий слоя, сквозных клавиш (pass-through) и включение/выключение определенных режимов навигации.

7. Вкладка "Порядок речи" (Speech Order)

  • Глобальный формат объявления: Измените способ, которым NVDA читает элементы глобально (например, По умолчанию: Имя -> Роль -> Состояние, или Состояние -> Роль -> Имя).
  • Настройка для отдельных ролей: Используйте поле поиска, чтобы найти конкретные роли (например, Флажок или Ссылка) и назначить для них уникальный формат объявления.

8. Вкладка "Профили приложений" (App Profiles)

  • Автоматически переключайте звуковые эффекты в зависимости от активного приложения.
  • Добавить профиль: Введите исполняемый файл приложения (например, chrome.exe) и назначьте конкретную аудио тему и/или пакет звуков набора текста, которые будут активироваться мгновенно при переключении на это приложение.

9. Вкладка "Быстрый поиск и закладки" (QuickSearch & Bookmarks)

  • Управление правилами навигации для конкретных доменов веб-браузера.
  • Назначьте клавиши (например, J или K) для быстрого перехода к определенным элементам (QuickJump), автоматического пропуска загроможденных меню (SkipClutter) или выполнения пользовательских скриптов Python на определенных веб-сайтах.

10. Вкладка "Первый/Последний элемент" (First/Last Item)

  • Включить обнаружение первого/последнего элемента: Воспроизводит уникальный звук "бампа" (столкновения), когда вы достигаете вершины или конца списка, меню или древовидного представления.
  • Область обнаружения: Применяйте это повсеместно ко всем ролям или выборочно к конкретным ролям (используя кнопку "Выбрать роли").
  • Поведение для одиночных элементов: Решите, должны ли элементы, которые являются единственными в списке, рассматриваться как первые, последние или полностью игнорироваться.

Использование Студии Аудио Тем V2 (Audio Themes Studio)

Студия Аудио Тем позволяет вам создавать и редактировать аудио темы. Чтобы открыть студию:

  1. Откройте меню NVDA (NVDA+N).
  2. Выберите "Студия Аудио Тем" (Audio Themes Studio).

В студии вы можете:

  • Создать новую аудио тему: Это проведет вас через процесс создания новой темы с нуля.
  • Настроить существующую аудио тему: Выберите эту опцию, чтобы изменить звуки установленной темы.
  • Запись с микрофона: Теперь вы можете записывать свой голос или любой другой звук напрямую с микрофона, чтобы назначить его на событие пользовательского интерфейса!
  • Перетаскивание (Drag & Drop): Вы можете перетаскивать аудиофайлы прямо в окно Студии для быстрого их назначения.
  • Облачный магазин тем: Просматривайте, прослушивайте и загружайте темы, созданные сообществом, прямо в Студии, без внешних браузеров.

Экспорт вашей темы

После создания или редактирования темы вы можете экспортировать ее как файл .atp, чтобы поделиться ею с другими. Вы найдете опцию экспорта на экране редактирования.

Расширенные правила и фонетическая пунктуация

Аудио иконы (Earcons) и речевые правила позволяют NVDA воспроизводить звуки, а также другие речевые эффекты, такие как изменение просодии.

Использование

  1. Убедитесь, что дополнение включено. Нажмите NVDA+Alt+P для его переключения.
  2. Правила можно настроить через диалоговое окно в меню настроек NVDA.
  3. По умолчанию у вас будет набор заранее определенных звуковых правил.
  4. Правила сохраняются в файле под названием earconsAndSpeechRules.json в каталоге конфигурации пользователя NVDA.

Детализация состояний (State Verbosity)

Дополнение включает функцию, которая позволяет отключать и скрывать речь или звуки для состояний, которые могут вызывать постоянное раздражение (например, состояния "развернуто" или "не выбрано"). Чтобы использовать эту функцию: 1. Перейдите в настройки речевых правил и отредактируйте состояние, которое вы хотите отключить. 2. Установите флажок напротив опции "Подавлять беспорядок состояний" (Suppress state clutter). 3. Теперь вы можете использовать быстрое сочетание клавиш для переключения уровня детализации в любое время. * Вы можете переключать эту опцию либо через комбинацию клавиш слоя (NVDA+Shift+A затем s), либо через прямую комбинацию (NVDA+Alt+[). * Когда вы уменьшаете детализацию, любое состояние, для которого вы включили эту опцию, будет отключено. Когда вы снова увеличите детализацию, дополнение вернется к нормальному чтению всех состояний.

Продвинутые функции и секреты

В это дополнение интегрирован ряд продвинутых функций, которые могут быть неочевидны на первый взгляд:

1. Слой навигации (Navigation Layer)

  • Горячая клавиша: NVDA+Win+N
  • Описание: Как только вы войдете в этот слой, вам больше не нужно будет удерживать Alt, Shift или любую другую клавишу-модификатор для навигации. Вы можете использовать только стрелки!
  • Как использовать:
  • Используйте стрелки влево/вправо для переключения между 27 различными режимами навигации (Символ, Слово, Строка, Предложение, Абзац, Заголовок, Ссылка, Кнопка, Поле редактирования, Таблица и т.д.).
  • Используйте стрелки вверх/вниз для перехода к предыдущему/следующему элементу в зависимости от текущего режима.
  • Нажмите C, чтобы скопировать текущий элемент в буфер обмена.
  • Нажмите S, чтобы прочитать текущий элемент по буквам.
  • Нажмите R, чтобы прочитать все, начиная с текущего элемента.
  • Нажмите Escape, чтобы выйти из слоя.

2. Аудио Сонар (Audio Sonar)

  • Горячая клавиша: NVDA+Alt+R (или NVDA+Shift+A затем r)
  • Описание: Невероятная функция, которая сканирует все активное окно, собирает все элементы управления внутри него (кнопки, списки, тексты) и быстро воспроизводит связанные с ними звуки слева направо в 3D-пространстве. Это дает вам звуковую "картину" того, как устроено окно и насколько оно заполнено!

3. Аудио маяк (Audio Beacon)

  • Горячая клавиша: NVDA+Shift+B (или NVDA+Shift+A затем a)
  • Описание: Вы можете "сбросить" аудио маяк в текущем местоположении объекта навигатора. Это полезно, чтобы отметить объект и контекстно отслеживать его во время сканирования аудио сонаром.

4. Слой команд Аудио Тем

  • Горячая клавиша: NVDA+Shift+A
  • Описание: Вместо того чтобы запоминать десятки комбинаций клавиш, войдите в этот слой и нажмите одну клавишу для выполнения команды:
  • t : Включить/выключить аудио темы.
  • p : Включить/выключить звуковые иконы и правила.
  • n и b : Следующая/Предыдущая тема.
  • Стрелка вверх и Стрелка вниз : Увеличить/Уменьшить громкость темы.
  • s : Включить/выключить детализацию состояний.
  • o : Быстро изменить Порядок речи (например, Имя затем Роль, или Роль затем Имя).
  • c : Озвучить текущий уровень заголовка.
  • y : Переключение тем.
  • i : Переключение звуков набора текста.
  • u : Включить/выключить звуки набора текста.
  • h : Справка.

5. Отчет об объектах в 3D (3D Object Reporting)

  • Горячая клавиша: NVDA+Tab
  • Описание: Сообщает о текущем объекте под курсором, но идеально сопоставляет его 3D-пространственные звуковые координаты, чтобы вы могли слышать его точное физическое расположение на вашем экране относительно центра.

6. Интеграция в системный трей (System Tray)

  • Описание: Дополнение внедряет параметры быстрого доступа прямо в меню системного трея NVDA. Вы можете щелкнуть правой кнопкой мыши значок NVDA рядом с часами на панели задач, чтобы мгновенно получить доступ к "Audio Themes Studio" или включить/выключить темы без необходимости открывать диалоговое окно полных настроек.

7. Звуки состояния системы (System Status Sounds)

  • Описание: Воспроизводит звуковые сигналы для событий системного уровня, таких как подключение/отключение USB-устройств, изменения питания от сети переменного тока, состояние батареи, подключение к сети и переход в спящий режим/выход из него. Все события отслеживаются через нативные уведомления Windows (без опроса).
  • События:
  • Питание подключено/отключено: Воспроизводит звук при подключении или отключении кабеля питания ноутбука.
  • Батарея разряжена/критически разряжена/полностью заряжена: Воспроизводит оповещения на основе пороговых значений, когда уровень заряда батареи падает ниже настраиваемых процентов или когда она полностью заряжена.
  • Устройство USB подключено/отключено: Обнаруживает любое подключение или извлечение USB-устройства (клавиатуры, мыши, флэш-накопители и т. д.).
  • Монтирование/размонтирование тома хранилища: Обнаруживает назначение буквы диска для флэш-накопителей, внешних жестких дисков и SD-карт.
  • Сеть подключена/отключена: Проверяет состояние подключения через настраиваемые интервалы и воспроизводит звук при изменении состояния.
  • Пробуждение/Сон системы: Воспроизводит звуки, когда компьютер выходит из спящего режима или переходит в него.
  • Пользовательские звуки: Поместите файлы .wav в папку вашей темы со следующими именами: sys_ac_plug.wav, sys_ac_unplug.wav, sys_battery_low.wav, sys_battery_critical.wav, sys_battery_full.wav, sys_usb_plug.wav, sys_usb_unplug.wav, sys_volume_plug.wav, sys_volume_unplug.wav, sys_network_connect.wav, sys_network_disconnect.wav, sys_wake.wav, sys_sleep.wav
  • Конфигурация: Откройте «Настройки NVDA» -> «Расширенные звуковые темы» -> вкладка «Состояние системы», чтобы включить/отключить отдельные события, отрегулировать громкость и установить пороговые значения батареи.

Change Log

Version 9.32

  • System Status Sounds: Added a completely new module to monitor and play sounds for system-level events (USB plug/unplug, AC power changes, battery status, network connectivity, and system wake/sleep) using native Windows notifications for zero lag.
  • Audio DSP Enhancements: Completely rewrote the Bass Boost (Low-shelf filter) and Noise Gate algorithms to support correct attack/release times and improved sound quality. Added a full UI in the settings panel to control these DSP effects.
  • 3D Spatial Audio Fixes: Resolved an issue causing lag in 3D audio playback for progress bars.

Version 9.30 - 9.31

  • Universal First/Last Item Detection: Added support for first/last item detection for all NVDA roles, instead of just lists and menus.
  • Advanced Detection Modes: Introduced 3 detection modes (smart, strict, any_sibling) with multi-hop traversal to guarantee accurate detection of the first and last elements even in complex web layouts.

Version 9.27 - 9.28

  • Role vs State Sounds Priority: Fixed an issue where state sounds (like "checked") were wrongly suppressing role sounds (like "checkbox").
  • Fallback Behaviors: Added custom fallback settings for first/last item sounds, allowing users to select custom sounds or bypass missing roles.
  • Heading Support: Added support for Heading levels 7, 8, and 9.

Version 9.23 - 9.26

  • Sentence Navigation Fixes: Fixed a bug causing NVDA to endlessly repeat sentences when reading Arabic text in VirtualBuffers.
  • NVDA 2026.2 Compatibility: Migrated to the new NVDAHelper.localLib.generateBeep API to resolve deprecation warnings and ensure stability on future NVDA versions.
  • Auto-Update Fix: Resolved a critical freeze in NVDA during the auto-update download process.
