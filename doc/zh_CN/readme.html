高级音频主题和语音标点符号 (Audio Themes NG & Phonetic Punctuation)

此附加组件通过为各种UI事件播放声音，为NVDA屏幕阅读器用户提供身临其境的音频体验。

主要功能

  • 音频效果: 为UI事件播放声音。
  • 3D音频: 使用Steam Audio提供3D定位音频。
  • 高级音频DSP: 低音增强，噪声门，静音修剪，智能音量标准化和包络线。
  • 音频闪避: 当NVDA说话时自动降低主题音量。
  • 混响: 为音频添加混响效果。
  • 音频主题工作室V2: 直接从麦克风或通过拖放创建或编辑音频主题。
  • 高级音频格式: FFmpeg支持MP3, FLAC, OGG, M4A等。
  • 高级打字声音: 具有空间音频定位和特殊按键映射的物理键盘模拟。
  • 音频信标/声纳: 在屏幕上放置空间音频信标并进行实时声纳探测。
  • 高级导航: SentenceNav和BrowserNav引擎，无冲突的箭头键。导航层（Navigation Layer）。
  • 云主题商店: 直接从工作室下载社区主题。
  • 应用程序配置文件: 自动为每个应用程序切换音频主题。

安装和使用

在NVDA设置中，选择"高级音频主题" (Advanced Audio Themes) 并勾选"启用音频主题" (Enable audio themes)。

设置选项卡概述

  • 常规 (General): 选择主题，应用商店，3D模式，打字声音。
  • 音频引擎 (Audio Engine): 正常化，静音修剪，噪声门，低音。
  • 混响 (Reverb): 模拟房间声学。
  • 音频格式: FFmpeg状态。
  • 语音标点符号规则: 强大的语音和状态声音规则引擎。
  • 杂项 (Miscellaneous): SentenceNav，BrowserNav设置。
  • 语音顺序 (Speech Order): 更改NVDA读取元素的顺序。
  • 应用配置文件 (App Profiles): 特定于应用程序的主题。
  • 快速搜索和书签 (QuickSearch & Bookmarks): 网页导航。
  • 第一个/最后一个元素: 列表边界声音。

状态冗长 (State Verbosity)

您可以隐藏烦人的状态（例如，"已展开"）：在语音规则设置中选中 "抑制状态混乱" (Suppress state clutter)，然后使用 NVDA+Shift+A，然后s 或 NVDA+Alt+[ 来切换。

高级功能和秘密 (Advanced Features & Secrets)

1. 导航层 (Navigation Layer)

NVDA+Win+N: 仅使用方向键浏览27种不同的导航模式，无需按住修饰键！

2. 音频声纳 (Audio Sonar)

NVDA+Alt+R: 扫描窗口中的所有元素并在3D空间中从左到右播放它们的声音！

3. 音频信标 (Audio Beacon)

NVDA+Shift+B: 在当前对象上"放置"一个音频信标。

4. 音频主题命令层

NVDA+Shift+A: 单键命令 (t-主题, p-规则, n/b-主题切换, s-状态详细, o-语音顺序)。

5. 3D对象报告

NVDA+Tab: 报告当前对象并映射其3D空间音频坐标。

6. 系统托盘集成

右键单击任务栏上的NVDA图标以快速访问工作室或切换主题。
